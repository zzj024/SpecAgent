# SpecAgent — 工程标准符合性审查多智能体系统

> 给一张设计图纸或一份技术文档，Agent 自动检索适用的标准规范条文，逐条核对，
> 输出**每个结论都挂证据链**的符合性审查报告；证据不足时分级拒答而不是硬答；
> 全程可审计、可断点续跑、可量化评测。

pgvector + BM25 混合检索加重排，LangGraph 编排支持断点续跑，全程轨迹审计，
用人工埋错法测漏报误报，检索做了三档对比评测。"
